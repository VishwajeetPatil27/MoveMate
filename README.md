# MoveMate — Relocation Infrastructure & Community Platform

MoveMate is a full-stack, community-driven relocation platform designed for individuals moving to new cities for employment, education, internships, business, or personal reasons.

---

## 🚀 Quick Run Instructions (VS Code Terminal)

### 1. Run Backend (Terminal 1)
```powershell
cd "c:\Users\vspat\OneDrive\Desktop - Copy\Desktop\MoveMate\backend"
mvn spring-boot:run
```

### 2. Run Frontend (Terminal 2)
```powershell
cd "c:\Users\vspat\OneDrive\Desktop - Copy\Desktop\MoveMate\frontend"
npm run dev
```

For detailed setup, database configuration, and test commands, see [HOW_TO_RUN.md](file:///c:/Users/vspat/OneDrive/Desktop%20-%20Copy/Desktop/MoveMate/HOW_TO_RUN.md).

---

## 🛠️ Technology Stack

- **Backend:** Java 21, Spring Boot 3.2.3, Spring Security 6, JWT, Spring Data JPA, Spring STOMP WebSockets
- **Database:** MySQL 8.0, Flyway Migrations (`V1` to `V9`)
- **Frontend:** React 18, TypeScript, Vite, Vanilla CSS Design System
